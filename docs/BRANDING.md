# EAROS Product Naming Boundary

**EAROS** is the sole product name for customer-facing interfaces, release documentation, operational runbooks, and recruiting workflows. New display copy, metadata, and user documentation must use EAROS.

The inherited recruiter API namespace, related code filenames, and historical task records remain implementation or provenance identifiers only. They are not product-facing names and must not be surfaced in the application UI, browser metadata, marketing copy, or new operational documents.

The architecture decision record may reference the former parallel prototype by name as historical context. That retained reference documents the migration decision and does not identify the EAROS product.
